# HTTP Methods in Go

HTTP methods describe the action a client wants a server to perform. In Go, they
are available as constants in the standard `net/http` package.

<details>
<summary>Quick memory guide</summary>

| Method | Meaning | CRUD action |
| --- | --- | --- |
| `GET` | Give me data | Read |
| `POST` | Create new data | Create |
| `PUT` | Replace the complete resource | Update |
| `PATCH` | Change part of a resource | Update |
| `DELETE` | Remove data | Delete |

</details>

## How a request works

```text
Client  -- HTTP method + URL + optional body -->  Go server
Client  <-- status code + response ---------------- Go server
```

The method is available through `r.Method`:

```go
package main

import (
		"fmt"
		"net/http"
)

func usersHandler(w http.ResponseWriter, r *http.Request) {
		switch r.Method {
		case http.MethodGet:
				fmt.Fprintln(w, "Get users")
		case http.MethodPost:
				fmt.Fprintln(w, "Create a user")
		case http.MethodPut:
				fmt.Fprintln(w, "Replace a user")
		case http.MethodPatch:
				fmt.Fprintln(w, "Partially update a user")
		case http.MethodDelete:
				fmt.Fprintln(w, "Delete a user")
		default:
				http.Error(w, "method not allowed", http.StatusMethodNotAllowed)
		}
}

func main() {
		http.HandleFunc("/users", usersHandler)
		http.ListenAndServe(":8080", nil)
}
```

## The five common methods

<details>
<summary>1. GET — retrieve data</summary>

`GET` reads data. It should not change the resource on the server.

```http
GET /users
GET /users/10
```

The first request gets all users; the second gets the user with ID `10`.

</details>

<details>
<summary>2. POST — create data</summary>

`POST` creates a new resource. The data is commonly sent in the request body.

```http
POST /users
Content-Type: application/json

{
	"name": "Rahim",
	"email": "rahim@example.com"
}
```

</details>

<details>
<summary>3. PUT — replace a complete resource</summary>

`PUT` replaces or updates the whole resource. Usually, the complete resource is
sent in the body.

```http
PUT /users/10
Content-Type: application/json

{
	"name": "Karim",
	"email": "karim@example.com",
	"age": 30
}
```

There is no standard `UPDATE` HTTP method. Use `PUT` or `PATCH` instead.

</details>

<details>
<summary>4. PATCH — update part of a resource</summary>

`PATCH` changes only the fields included in the request. Other fields stay the
same.

Existing user:

```json
{
	"name": "Rahim",
	"email": "rahim@example.com",
	"age": 25
}
```

Request:

```http
PATCH /users/10
Content-Type: application/json

{
	"name": "Karim"
}
```

After the request, `email` and `age` remain unchanged.

</details>

<details>
<summary>5. DELETE — remove data</summary>

`DELETE` removes a resource identified by the URL.

```http
DELETE /users/10
```

This means: delete the user whose ID is `10`.

</details>

## PUT vs PATCH

| `PUT` | `PATCH` |
| --- | --- |
| Full replacement | Partial modification |
| Usually sends every field | Sends only changed fields |
| Replaces the resource representation | Keeps fields that were not included |

### Example

For this existing user:

```json
{
	"name": "Rahim",
	"email": "rahim@example.com",
	"age": 25
}
```

`PUT /users/10` sends the complete replacement:

```json
{
	"name": "Karim",
	"email": "karim@example.com",
	"age": 30
}
```

`PATCH /users/10` sends only the required change:

```json
{
	"name": "Karim"
}
```

## Try it yourself

1. Save the Go example as `main.go`.
2. Run the server with `go run main.go`.
3. In another terminal, try each request:

```bash
curl http://localhost:8080/users
curl -X POST http://localhost:8080/users
curl -X PUT http://localhost:8080/users
curl -X PATCH http://localhost:8080/users
curl -X DELETE http://localhost:8080/users
```

<details>
<summary>Self-check quiz</summary>

- Which method is normally used to read users? **GET**
- Which method creates a new user? **POST**
- Which method changes only a user's name? **PATCH**
- Which method removes user `10`? **DELETE**
- Which method sends a complete replacement? **PUT**

</details>
